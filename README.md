# Network Security and Scanning

This repository contains the practical work completed as part of my cybersecurity internship.

## Objectives

- Understand basic network security concepts
- Perform network reconnaissance
- Identify hosts and network information
- Perform port and service scanning using Nmap
- Analyze vulnerabilities using OpenVAS/GVM
- Capture and analyze network packets using Wireshark
- Understand firewall rules using iptables
- Document practical cybersecurity activities and findings

## Tools Used

- Kali Linux
- Nmap
- OpenVAS / Greenbone Vulnerability Management
- Wireshark
- iptables
- Metasploitable2

## Lab Environment

The practical exercises are performed in an authorized virtual lab environment using Kali Linux and Metasploitable2.
